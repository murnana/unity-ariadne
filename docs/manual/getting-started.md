# GuidGraph 入門マニュアル

Windows と、Apple Silicon の Mac を対象にしています。Linux と Intel の Mac には対応していません。

## このマニュアルでできること

Unity のプロジェクトについて、Claude Code に日本語で質問できるようになります。たとえば「このマテリアルはどこで使われていますか」と質問できます。Claude Code は、Anthropic の AI コーディングツールです。

## はじめる前に準備するもの

- Windows のパソコン、または Apple Silicon の Mac
- インターネット接続
- 調べたい Unity のプロジェクト(`Assets` フォルダがあるもの)
- Claude Code を使えるアカウント
  - Pro、Max、Team、Enterprise などの有料プラン、または Console のアカウントが必要です。
  - claude.ai の無料プランでは使えません。料金は申し込む前に確認してください。
- パソコンにソフトを入れる権限

### 始める前に確認してください

- **情報の送信**:質問すると、調べた結果が Anthropic などの AI サービスへ送られます。結果には、ファイル名やコード内の説明文が含まれます。仕事のプロジェクトでは、先に責任者の許可を得てください。
- **ソフトの追加**:会社や学校のパソコンでは、先に管理者の許可を得てください。

### Unity の設定

- Unity の「Asset Serialization」が「Force Text」であることを確認します。【要確認:設定画面の場所】
- 「Force Text」でないファイルの中身は、調べられません。
- 設定を変えると、多くのファイルが書き換わることがあります。変える前に控えを取ってください。
- プロジェクトを Unity で一度開いておきます。パッケージの中のファイルも調べられるようになります。

## 手順

灰色の枠の命令は、文字で命令を入力する画面に入力します。1行ずつ入力して、Enter キーを押します。

### 1. 命令を入力する画面を開く

- Windows:スタートメニューで「PowerShell」を探して開きます。
- Mac:「ターミナル」を開きます。

### 2. Claude Code を入れる

すでに入っている場合は、手順3に進みます。

次の命令は、Anthropic のサイトから取得したプログラムをすぐに実行します。

Windows(PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Mac:

```sh
curl -fsSL https://claude.ai/install.sh | bash
```

終わったら、画面を一度閉じて、開き直します。

### 3. Claude Code が入ったことを確認する

```sh
claude --version
```

版の番号が表示されます。

### 4. Claude Code にログインする

1. 次の命令を入力します。

   ```sh
   claude
   ```

2. ブラウザーに表示される案内に従って、ログインします。
3. ログインできたら、Claude Code の入力欄に `/exit` と入力して終了します。【要確認:終了の操作】

### 5. Node.js を入れる

Node.js は、このあと追加する機能を動かすためのソフトです。版は 20.12 以降が必要です。

1. [Node.js のダウンロードページ](https://nodejs.org/en/download)を開きます。
2. 自分のパソコン向けのインストーラーを取得して開きます。Windows は `.msi` のファイルです。【要確認:Mac 向けのファイルの種類】
3. 画面の案内に従って入れます。

### 6. GuidGraph を入れる

1. [GuidGraph の配布ページ](https://github.com/murnana/unity-guidgraph/releases)を開きます。
2. 一番新しい版の「Assets」から、次のファイルを取得します。【要確認:次の版のファイル名】
   - Windows:名前の最後が `win-x64.msi` のファイル
   - Mac:名前の最後が `osx-arm64.pkg` のファイル
3. 取得したファイルを開きます。

このファイルには、作成者を証明する署名がありません。そのため、初回は警告が表示されます。

- 配布ページから取得したファイルであることを確認してから、実行を許可します。【要確認:警告画面で押すボタン】
- 会社や学校のパソコンで判断できない場合は、管理者に相談してください。

### 7. 準備ができたことを確認する

1. 命令を入力する画面と Claude Code をすべて閉じて、開き直します。
2. 次の命令を1行ずつ入力します。

   ```sh
   node --version
   ```

   ```sh
   guidgraph --help
   ```

1つ目は版の番号が表示されます。20.12 以降であることを確認します。2つ目は「usage:」で始まる使い方の一覧が表示されます。

### 8. Claude Code に GuidGraph の機能を追加する

追加する機能を「プラグイン」と呼びます。次の命令を1行ずつ入力します。【要確認:配布元での公開と、プラグインの名前】

```sh
claude plugin marketplace add murnana/murnana-claude-code-plugin
```

```sh
claude plugin install unity-guidgraph@murnana-claude-code-plugin
```

1つ目はプラグインの配布元を登録する命令です。2つ目はプラグインを入れる命令です。それぞれ、完了の表示を確認します。【要確認:表示される文】

### 9. Unity のプロジェクトで Claude Code を起動する

起動すると、プロジェクトを調べた結果のファイル(`graph.db`)が自動で作られます。

- このファイルは、プロジェクトのフォルダの外に保存されます。
- 30日間使わないと、自動で削除されます。もう一度起動すると、作り直されます。
- 大きなプロジェクトは時間がかかり、時間切れになることがあります。

1. `Assets` フォルダがある場所へ移動します。次の `プロジェクトの場所` は、自分の場所に置き換えます。`"` は残します。

   ```sh
   cd "プロジェクトの場所"
   ```

2. Claude Code を起動します。大きなプロジェクトでは、待ち時間を10分に延ばして起動します。

   Windows(PowerShell):

   ```powershell
   $env:MCP_TIMEOUT = "600000"
   ```

   ```powershell
   claude
   ```

   Mac:

   ```sh
   MCP_TIMEOUT=600000 claude
   ```

3. フォルダを信用するかを聞かれた場合は、自分のプロジェクトであることを確認して許可します。【要確認:表示される文】

### 10. つながったことを確認する

Claude Code の入力欄に、次のとおり入力します。

```text
/mcp
```

一覧の「plugin:unity-guidgraph:guidgraph」に、チェックの印が表示されます。「×」の印の場合は、「よくある質問」を見てください。

### 11. 質問する

Claude Code の入力欄に質問を入力します。`Player.prefab` は、自分のプロジェクトのファイル名に置き換えます。

```text
Player.prefab はどこで使われていますか
```

使っているファイルの一覧などが回答されます。途中で操作の許可を聞かれた場合は、内容を確認して選びます。

**ファイルを削除する前に**:一覧に何も出なくても、使われていないとは限りません。控えを取り、Unity で動作を確認してください。調べられない参照は、[limitations.md](limitations.md) にまとめています。

### 12. ファイルを変えたあとに結果を新しくする

調べた結果は、自動では新しくなりません。Unity のファイルを変えたら、次のように入力します。

```text
グラフを更新して
```

更新の結果が報告されます。

## よくある質問

**Q. 「claude」「node」「guidgraph」が見つからないと表示されます。**

命令を入力する画面と Claude Code をすべて閉じて、開き直します。直らない場合は、そのソフトを入れる手順をもう一度実行します。

**Q. `/mcp` で「×」の印が表示されます。**

次を順に確認します。

1. `Assets` フォルダがある場所で Claude Code を起動しているか。
2. 手順7の2つの命令が動くか。
3. 大きなプロジェクトの場合は、手順9の待ち時間を延ばした方法で起動したか。

**Q. 「does not look like a Unity project」と表示されます。**

Claude Code を終了します。`Assets` フォルダがある場所へ移動して、起動し直します。

**Q. プラグインを消したいです。**

次の命令を入力します。調べた結果のファイルも削除されます。Unity のプロジェクトは削除されません。【要確認:命令の動き】

```sh
claude plugin uninstall unity-guidgraph@murnana-claude-code-plugin
```

**Q. 解決しない場合はどうすればよいですか。**

[GuidGraph の Issues](https://github.com/murnana/unity-guidgraph/issues) で報告できます。報告は誰でも読めます。仕事の情報やファイル名は書かないでください。
